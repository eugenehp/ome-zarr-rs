# Sample images

Copied from scikit-image's `skimage/data` directory.

* `coins.png` — from the Brooklyn Museum Collection
  (<https://www.brooklynmuseum.org/opencollection/archives/image/51611>);
  "No known copyright restrictions" (scikit-image's notes).
* `astronaut.png` — Eileen Collins, NASA astronaut, from the NASA Great Images
  database (<https://flic.kr/p/r9qvLn>); "No known copyright restrictions,
  released into the public domain" (scikit-image's notes).

They are embedded in the binary and used by `ome_zarr create`
(`ome_zarr::data::coins` / `astronaut`).
